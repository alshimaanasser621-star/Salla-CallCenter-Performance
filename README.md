# Salla Call Center Performance Dashboard

##  Project Overview
Analysis of Salla call center performance data
covering February to April 2022 using Power BI.

##  Tools Used
- Power BI Desktop
- Data Modeling & DAX
- Data Visualization

##  Key Questions Answered
- What is the overall service level?
- Which project has the highest call volume?
- How does actual calls compare to forecasted calls?
- Which agents handle the most calls?
- What is the abandon rate trend over time?

##  Key Insights
- Total Calls Offered: 1.74M
- Calls Handled: 1.72M
- Service Level: 92.28%
- Abandon Rate: 1.32%
- Project B has the highest call volume at 51%
- Top Agent: Huda with 2.97% of total calls
